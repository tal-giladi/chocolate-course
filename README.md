# שוקולד בעבודת יד: מהמטבח הביתי ועד חנות אונליין

קורס מעשי בעברית: מטבלאות שוקולד ראשונות, דרך טמפרור, בונבונים, סביבונים ומארזי חג, ועד חנות שוקולד אונליין קטנה בישראל. בכל שיעור תרגול בכמויות קטנות, חלופות טבעוניות ובריאות יותר והערת כשרות.

## למי הקורס

מבוגרים בלי ניסיון בקונדיטוריה שרוצים להכין שוקולד יפה לעצמם ולמתנות, ואולי למכור. מתאים לשומרי כשרות ברמות שונות, לטבעונים ולמי שמחפש פחות סוכר.

## מה צריך

מטבח עם כיריים או מיקרוגל, מקרר, משקל דיגיטלי ומדחום. ערכת ציוד בסיסית עולה בערך 300-600 ₪ (שיעור 01.2).

## מבנה הקורס

| חלק | מודולים | למי |
|---|---|---|
| א — יסודות | 1-3 | כולם מתחילים כאן |
| ב — מוצרים ועיצוב | 4-11 | בית ומתנות |
| ג — חלופות | 12-14 | טבעוני, פרווה, פחות סוכר, אלרגיות |
| ד — עסק | 15-21 | מי שרוצה למכור; מומלץ לסיים קודם את מודולים 1-6 |

## איפה קונים

הקורס נכתב לשוק הישראלי, עם קישורים לחנויות מקומיות ובדיקת כשרות לכל חומר גלם ב[איפה קונים](references/where-to-buy.md) וב[מדריך הכשרות](references/kashrut-guide.md). כל כלי וחומר גלם מתואר כך שאפשר למצוא אותו בכל חנות, בכל מקום.

## חשוב לדעת

הקורס לא פוסק הלכה: כשרות לפי מה שכתוב על האריזה, ושאלות לרב. המסלול העסקי נותן מידע כללי ולא ייעוץ משפטי, מס או רישוי; בודקים מול הרשויות לפני שמוכרים.
