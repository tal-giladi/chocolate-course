# תווית מוצר

רשימה לתכנון תווית. הדרישות המחייבות מופיעות ב[שיעור 18.1](../lessons/module-18/lesson-01.md) ובמקורות הרשמיים שם, ונבדקות מחדש לפני הדפסה.

| שדה | מה כותבים |

| שם המוצר | |
| רשימת רכיבים, בסדר יורד לפי משקל | |
| רכיבי משנה מהמפרט (לפי אצוות הספק) | למשל: שוקולד מריר (מסת קקאו, סוכר, חמאת קקאו, מתחלב: לציטין סויה) |
| אלרגנים (מודגשים) | |
| "עלול להכיל" | |
| משקל נטו | |
| תאריך (לשימוש עד / ייצור) | |
| הוראות אחסון | למשל "לשמור בקופסה סגורה ב־18-20°C" או "לשמור במקרר עד 4°C" ([16.3](../lessons/module-16/lesson-03.md)) |
| שם וכתובת היצרן | |
| סימון תזונתי | |
| כפיות סוכר (אם נדרש) | |
| סמלים בחזית האריזה (אם חלים): קוטר סמל / שטח חזית | |
| כשרות (רק עם תעודה) | בלי תעודה: ריק. עם תעודה: גוף הכשרות, סטטוס (חלבי / פרווה), חלב ישראל, פסח, לפי התעודה ([17.3](../lessons/module-17/lesson-03.md)) |

- [ ] כל הרכיבים, כולל רכיבים של רכיבים (למשל לציטין סויה בשוקולד)

- [ ] אין טענות בריאות שאסור לכתוב
- [ ] אין "כשר" או סימן כשרות בלי תעודה בתוקף
- [ ] מספר אצווה והוראת אחסון כתובים
