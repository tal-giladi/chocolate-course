# תווית מוצר

רשימה לתכנון תווית. הדרישות המחייבות מופיעות בשיעור 18.1 ובמקורות הרשמיים שם, ונבדקות מחדש לפני הדפסה.

| שדה | מה כותבים |
|---|---|
| שם המוצר | |
| רשימת רכיבים, בסדר יורד לפי משקל | |
| אלרגנים (מודגשים) | |
| "עלול להכיל" | |
| משקל נטו | |
| תאריך (לשימוש עד / ייצור) | |
| הוראות אחסון | |
| שם וכתובת היצרן | |
| סימון תזונתי | |
| סמלים בחזית האריזה (אם חלים) | |
| כשרות (רק עם תעודה) | |
| אזהרה על ממתיקים (אם יש) | |
| מספר אצווה | |

## בדיקה לפני הדפסה

- [ ] כל הרכיבים, כולל רכיבים של רכיבים (למשל לציטין סויה בשוקולד)
- [ ] אלרגנים תואמים את הרכיבים ואת הציוד המשותף
- [ ] אין טענות בריאות שאסור לכתוב
- [ ] אין "כשר" או סימן כשרות בלי תעודה בתוקף
- [ ] בעברית, קריא
