# תבניות

תבניות להעתקה ולמילוי. מעתיקים לקובץ או למחברת משלכם, או מדפיסים. השיעורים מפנים לתבנית המתאימה.

- [יומן תרגול](practice-log.md) — מה הכנתי, טמפרטורות, מה יצא ומה אשנה בפעם הבאה.
- [יומן טמפרור](tempering-log.md) — שיטה, טמפרטורות ובדיקת טמפר.
- [כרטיס מתכון](recipe-card.md) — רכיבים בגרסת תרגול ובגרסה מלאה, חלופות, אלרגנים וכשרות.
- [תכנון מארז](gift-box-plan.md) — פריטים, אריזה ועלות למארז.
- [גיליון תמחור](pricing-sheet.md) — חומרי גלם, אריזה, עבודה, פחת, עמלות ומחיר.
- [תווית מוצר](product-label.md) — כל מה שצריך להופיע על תווית של מוצר שמוכרים.
- [מחקר שוק](market-research.md) — מתחרים, מחירים, גודל מארז ועונתיות.
- [תוכנית עסקית קצרה](business-plan.md) — נישה, מוצרים, מחירים, ערוצים ותוכנית השקה.
- [תכנון ייצור לעונה](production-plan.md) — כמה מייצרים, מתי, ובאיזה סדר.
- [דף טעימה](tasting-sheet.md) — ברק, סנאפ, ריח, טעם, המסה וסיומת לכל דגימה.
- [ניסוי חיי מדף](shelf-life-trial.md) — אצווה, שני תנאי אחסון, נקודות בדיקה, דף ציון והחלטה על התאריך.
- [תוכנית בטיחות מזון](food-safety-plan.md) — שבעה חלקים: תיאור העסק, דף סכנות, תוכניות קדם, אלרגנים, אחסון ומסירה, רשומות וריקול, רישוי.
- [מדיניות החנות ויומן פניות](shop-policies.md) — משלוחים, ביטול והחזרות, יצירת קשר, יומן פניות ותבניות תשובה.
- [הצעת מחיר לחברה](corporate-quote.md) — מוצר, מדרגות מחיר, מע"מ ומסמך, מועדים ומקדמה.
- [לוח תוכן לחג](content-calendar.md) — 8 שבועות של פוסטים לפני החג, עם בדיקת ארבעת הכללים.
