# פרויקט: גרסה עם פחות סוכר מול המקור

בפרויקט הזה לוקחים מוצר אחד שכבר הכנתם בקורס ומכינים אותו בשתי גרסאות זו לצד זו: המקור, וגרסה עם פחות סוכר. מודדים, מחשבים, טועמים עיוור ושומרים שבוע, ובסוף כותבים לגרסה החדשה תווית בלי טענות בריאות. הפרויקט משלב את כל המודול: מה באמת משתנה במספרים ([13.1](../lessons/module-13/lesson-01.md)), ממתיקים ואזהרת המלטיטול ([13.2](../lessons/module-13/lesson-02.md)), תמרים ובטיחות ([13.3](../lessons/module-13/lesson-03.md)), אגוזים ותוספות ([13.4](../lessons/module-13/lesson-04.md)), ומה מותר לכתוב ([13.5](../lessons/module-13/lesson-05.md)). המטרה היא לא להוכיח שהגרסה החדשה "טובה יותר", אלא לדעת בדיוק במה היא שונה.

## המשימה

1. **בוחרים מוצר מקור** שכבר הכנתם: דיסקיות או מנדיאנטים ([02.3](../lessons/module-02/lesson-03.md)), טבלה ([04.2](../lessons/module-04/lesson-02.md)), טראפלס ([06.2](../lessons/module-06/lesson-02.md)) או חטיף ([07.4](../lessons/module-07/lesson-04.md)). כמות: 8 יחידות.
2. **בוחרים דרך אחת או שתיים להוריד סוכר**, מתוך ארבע:
   - אחוז קקאו גבוה יותר (למשל חלב או 55% ← 70%);
   - יחידה קטנה יותר (למשל 20 גרם ← 10 גרם);
   - ממתיק במקום סוכר (שוקולד ללא תוספת סוכר עם מלטיטול, [13.2](../lessons/module-13/lesson-02.md));
   - תוספות שמדללות את השוקולד (אגוזים וזרעים, [13.4](../lessons/module-13/lesson-04.md)).
   תמרים וסילאן ([13.3](../lessons/module-13/lesson-03.md)) אפשר לבחור רק אם המוצר הוא כדור או מילוי, לא שוקולד מטומפר, ורק אחרי שבדקתם בחישוב שהם באמת מורידים סוכר ליחידה.
3. **מכינים 8 יחידות מכל גרסה** באותו יום, באותה תבנית או באותו גודל (חוץ מאשר כשהגודל הוא השינוי).
4. **מחשבים ליחידה** סוכר, שומן רווי ואנרגיה בשתי הגרסאות, ואת אחוז השינוי.
5. **עורכים טעימה עיוורת** עם 2-3 טועמים, לפי דף הטעימה מ־[01.5](../lessons/module-01/lesson-05.md).
6. **שומרים שבוע** שתי יחידות מכל גרסה באותם תנאים, ובודקים ביום 1, 3 ו־7.
7. **כותבים תווית** לגרסה עם פחות הסוכר לפי [13.5](../lessons/module-13/lesson-05.md).

## מה צריך

| פריט | כמות | הערה |
|---|---|---|
| שוקולד לגרסת המקור | לפי המתכון, 250 גרם לטמפרור | שאריות מהמודולים הקודמים, נמסות מחדש |
| שוקולד לגרסה עם פחות סוכר | 250 גרם לטמפרור | מריר 70%, או ללא תוספת סוכר עם מלטיטול |
| תוספות | לפי הבחירה | אגוזים קלויים, זרעים, פירות מיובשים בהקפאה |
| מדחום, משקל (רצוי 0.1 גרם), תבנית או אצטט, שקית זילוף | | |
| שני סוגי מדבקות או צבעים לסימון הגרסאות | | הטועמים לא יודעים איזו גרסה זו |
| קופסאות אטומות | 2 | לבדיקת האחסון |
| התוויות של כל הרכיבים | | לחישוב |

אלרגנים: לפי המוצר. שוקולד מכיל בדרך כלל לציטין סויה, ו"עלול להכיל" חלב, אגוזים או בוטנים; שוקולד חלב ולבן מכילים חלב; תוספות יכולות להוסיף אגוזים, בוטנים ושומשום. כותבים רשימת אלרגנים לכל גרסה בנפרד. אם יש מלטיטול: שתי היחידות לטעימה הן המנה לטועם, והטועמים הם מבוגרים שיודעים מה יש בה.

> [!CAUTION]
> מלטיטול גורם לגזים ולשלשול כשאוכלים ממנו כמות, והוא לא מתאים לילדים בכמויות. אומרים לטועמים מראש שאחת הגרסאות עשויה להכיל ממתיק, ולא מחלקים את שאר היחידות לילדים.

כשרות: כל רכיב בכשרות שמתאימה לכם, לפי מה שכתוב על האריזה ([שלושה כללים](../references/kashrut-guide.md#שלושה-כללים), [שוקולד ללא סוכר](../references/kashrut-guide.md#שוקולד-ללא-סוכר), [ממתיקים](../references/kashrut-guide.md#ממתיקים)). שימו לב ששוקולד ללא סוכר יכול להיות חלבי גם כשהוא מריר.

## שלבים

1. **תכנון** (20 דקות): ממלאים שני [כרטיסי מתכון](../templates/recipe-card.md), אחד לכל גרסה, עם אותו מבנה: רכיבים בגרמים, משקל יחידה, אלרגנים, כשרות. בכרטיס של הגרסה החדשה כותבים איזו דרך בחרתם ולמה.
2. **הכנת גרסת המקור** (40 דקות): לפי השיעור המקורי. מטמפרים לפי [03.2](../lessons/module-03/lesson-02.md) ורושמים ב[יומן הטמפרור](../templates/tempering-log.md).
3. **הכנת הגרסה עם פחות סוכר** (40 דקות): באותו יום. שוקולד עם מלטיטול מטמפרים לפי עקומת היצרן ([13.2](../lessons/module-13/lesson-02.md)). אגוזים קולים ומקררים לגמרי ([13.4](../lessons/module-13/lesson-04.md)).
4. **שקילה**: שוקלים כל יחידה בשתי הגרסאות ורושמים ממוצע.
5. **חישוב** (20 דקות): מכל תווית לוקחים סוכרים, שומן רווי ואנרגיה ל־100 גרם, מחשבים לכל רכיב (ערך × גרם ÷ 100) ומחברים ליחידה, כמו בטבלה של [13.4](../lessons/module-13/lesson-04.md). ממלאים:

   | ליחידה | מקור | פחות סוכר | שינוי |
   |---|---|---|---|
   | משקל (גרם) | | | |
   | סוכרים (גרם) | | | % |
   | רב־כוהלים (גרם), אם יש | | | |
   | שומן רווי (גרם) | | | % |
   | אנרגיה (קק"ל) | | | % |

6. **טעימה עיוורת** (30 דקות): מישהו אחר מסמן את היחידות בצבע או במספר. כל טועם מקבל חצי יחידה מכל גרסה, ממלא [דף טעימה](../lessons/module-01/lesson-05.md) (מראה, מגע, צליל, ריח, טעם, מרקם, סיומת), ועונה על שתי שאלות: איזו גרסה מתוקה יותר? איזו הייתם קונים?
7. **בדיקת אחסון**: שתי יחידות מכל גרסה בקופסה אטומה, באותו מקום (18-20°C; כדורי תמרים או מילוי עם שמנת במקרר). ביום 1, 3 ו־7 רושמים: ברק, פריחה, פריכות של תוספות, ריח, טעם.
8. **תווית** (30 דקות): לגרסה עם פחות הסוכר ממלאים [תווית מוצר](../templates/product-label.md) לפי [13.5](../lessons/module-13/lesson-05.md): שם עובדתי, רכיבים עם הממתיק בשמו, אלרגנים, טבלה ל־100 גרם עם רב־כוהלים, אזהרות, ושורת "נבדק בתאריך". אם אתם רוצים לכתוב "מופחת סוכר", צריך הפחתה של 30% לפחות לפי החישוב שלכם.
9. **מה שנשאר**: יחידות עודפות נאכלות או נמסות לשוקו, שאריות שוקולד מטומפר לטבלה, שאריות עם מלטיטול בשקית מסומנת.

## מה מגישים

הפרויקט לא נשלח לבדיקה. האקדמיה לא בודקת צילומים, ואתם בודקים את עצמכם לפי הטבלה בהמשך. בסוף יש לכם:

- 8 יחידות מכל גרסה, וצילום שלהן זו לצד זו באותה תאורה.
- שני כרטיסי מתכון וטבלת החישוב ליחידה, עם אחוזי השינוי.
- דפי הטעימה של כל הטועמים, וסיכום של שלוש שורות.
- טבלת אחסון ליום 1, 3 ו־7.
- תווית מלאה לגרסה עם פחות הסוכר, בלי טענות בריאות.
- שלושה משפטים: מה השתנה במספרים, מה השתנה בטעם ובמרקם, ואיזו גרסה הייתם מכינים שוב ולמה.

## בדיקה עצמית

| קריטריון | עומד בדרישה | צריך עוד עבודה |
|---|---|---|
| השוואה הוגנת | אותו מוצר, אותו יום, אותו גודל (אלא אם הגודל הוא השינוי), ורק דרך אחת או שתיים משתנות | שינו גם מתכון וגם טכניקה וגם גודל, ואי אפשר לדעת מה עשה את ההבדל |
| טמפר | שתי הגרסאות מבריקות, עם סנאפ, ויוצאות מהתבנית | גרסה אחת מפוספסת או רכה |
| חישוב | סוכר, שומן רווי ואנרגיה ליחידה לשתי הגרסאות, מחושבים מהתוויות, עם אחוזי שינוי | חישוב רק של סוכר, או בלי לחלק ב־100 |
| הבנה | שלושת המשפטים מסבירים גם מה **לא** השתנה (למשל קלוריות) | "יצא בריא יותר" בלי מספרים |
| טעימה עיוורת | 2-3 טועמים, דף טעימה מלא, והטועמים לא ידעו איזו גרסה | טעימה פתוחה, או טועם אחד |
| אחסון | בדיקה ביום 1, 3 ו־7 לשתי הגרסאות באותם תנאים | בלי בדיקה, או בתנאים שונים |
| בטיחות | אזהרת מלטיטול לטועמים (אם יש); אגוזים קלויים ומקוררים; מוצר עם תמרים או שמנת במקרר | טועמים לא ידעו על מלטיטול, או מוצר רגיש נשאר בחוץ |
| תווית | בלי "בריא", "מחזק", "מתאים לסוכרתיים"; ממתיק בשמו; רב־כוהלים בשורה נפרדת; אלרגנים; "מופחת" רק עם 30% מחושבים | טענת בריאות, ממתיק בשורת הסוכרים, או אלרגן חסר |
| בלי בזבוז | כל מה שלא נטעם נאכל, נמס לשוקו או נכנס לאפייה, ושאריות עם מלטיטול מסומנות | שוקולד או מוצרים נזרקו (חוץ ממוצר עם עובש) |

עמדתם בכל השורות? יש לכם מוצר אחד בשתי גרסאות שאתם יכולים להסביר במספרים, וזה בסיס טוב לקו "פחות סוכר" במסלול העסקי (מודולים 15 ו־18). נכשלתם בשורה אחת או שתיים? חוזרים רק על הגרסה החלשה, ב־4 יחידות.
