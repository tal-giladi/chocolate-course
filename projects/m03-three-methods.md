# פרויקט: שלוש שיטות טמפרור

בפרויקט הזה מטמפרים את אותו שוקולד שלוש פעמים, בשלוש שיטות: הזרעה, משטח וחמאת קקאו באבקה. בסוף יש שלוש טבלאות מבריקות, יומן טמפרור מלא והחלטה מנומקת איזו שיטה מתאימה למטבח שלכם. זו גם הבדיקה שלכם לפני [מודול 4](../lessons/module-04/lesson-01.md) ו[מודול 5](../lessons/module-05/lesson-01.md): מי שעומד בבדיקה העצמית כאן מוכן לבונבונים.

## המשימה

לטמפר 300 גרם שוקולד מריר שלוש פעמים, פעם בכל שיטה, ולצקת מכל פעם טבלה אחת. משתמשים באותו שוקולד בכל הסבבים: אחרי שהטבלה של סבב אחד נבדקה ונרשמה, ממיסים אותה (יחד עם השאריות) לסבב הבא. כך כל הפרויקט עולה 300-400 גרם שוקולד ולא קילו. בכל סבב מתעדים טמפרטורות, בודקים את התוצאה בשש הבדיקות של [שיעור 03.5](../lessons/module-03/lesson-05.md), ומצלמים.

אין אבקה? מחליפים את הסבב השלישי בהזרעה של שוקולד חלב או לבן, בטמפרטורות שלהם.

## מה צריך

| פריט | כמות | הערה |
|---|---|---|
| קוברטורה מריר 50-70% | 300 גרם, ועוד 100 גרם זרעים | אפשר את השוקולד מהשיעורים, כולל שאריות ופריחות, אם הוא מאותו מוצר |
| חמאת קקאו באבקה | 3 גרם | 1% |
| מדחום דיגיטלי עם דקר | 1 | |
| משקל מטבח ומשקל דיוק 0.1 גרם | 1 מכל | |
| משטח שיש או גרניט, מרית פלטה וקלף | 1 מכל | לסבב המשטח |
| תבנית טבלה אחת (עדיף פוליקרבונט) | 1 | משתמשים בה שלוש פעמים |
| מדחום חדר | 1 | מומלץ |
| מצלמה (טלפון) | | |

אלרגנים: קוברטורה מכילה בדרך כלל לציטין סויה, ולעתים חלב, או "עלולה להכיל" חלב ואגוזים. בודקים על האריזה. כשרות: כל הסבבים מאותו מוצר, וזרעים ואבקה בכשרות שמתאימה לכם ([שלושה כללים במדריך הכשרות](../references/kashrut-guide.md#שלושה-כללים)).

## שלבים

1. **הכנה**: פותחים עותק של [יומן הטמפרור](../templates/tempering-log.md). בוחרים יום ושעה שבהם החדר הכי קריר (בקיץ: מזגן, או בוקר מוקדם). מודדים ורושמים את טמפרטורת החדר.
2. **סבב 1, הזרעה** ([03.2](../lessons/module-03/lesson-02.md)): 200 גרם מומסים ל־45-50°C, זרעים עד 31-32°C, בדיקת סכין, טבלה.
3. **בדיקה ותיעוד**: אחרי שהטבלה יצאה מהתבנית, שש הבדיקות של [03.5](../lessons/module-03/lesson-05.md), צילום (צד התבנית וקו השבר), ושורה ביומן.
4. **סבב 2, משטח** ([03.3](../lessons/module-03/lesson-03.md)): ממיסים את הטבלה מסבב 1 ומשלימים ל־300 גרם, מקררים 200 גרם על המשטח ל־27-28°C, מחזירים, 31-32°C, בדיקת סכין, טבלה. בדיקה ותיעוד.
5. **סבב 3, חמאת קקאו באבקה** ([03.4](../lessons/module-03/lesson-04.md)): ממיסים את הטבלה מסבב 2 ל־40-45°C, מקררים ל־34-35°C, 3 גרם אבקה, ערבוב עד 31-32°C, בדיקת סכין, טבלה. בדיקה ותיעוד.
6. **השוואה**: מניחים את שלוש הטבלאות זו ליד זו (אם המסתם אותן, משתמשים בצילומים ובחתיכה קטנה ששמרתם מכל סבב). מצלמים באותה תאורה.
7. **החלטה**: כותבים 3-5 משפטים: איזו שיטה הכי מתאימה למטבח שלכם ולמה (זמן, ציוד, חום בחדר, כמה פעמים הצלחתם בבדיקת הסכין בפעם הראשונה).
8. **מה שנשאר**: הטבלה האחרונה נשארת שלכם, לאכילה או ל[מודול 4](../lessons/module-04/lesson-01.md). כל שארית או טבלה שלא הצליחה נכנסת לשקית "להמסה", או לשוקו חם ולבראוניז.

## מה מגישים

הפרויקט לא נשלח לבדיקה. האקדמיה לא בודקת צילומים, ואתם בודקים את עצמכם לפי הטבלה בהמשך. בסוף יש לכם:

- יומן טמפרור עם שלוש שורות מלאות: שיטה, טמפרטורות המסה, קירור ועבודה, טמפרטורת החדר, זמן ההתקשות בבדיקת הסכין, ותוצאה.
- שישה צילומים לפחות: צד התבנית וקו השבר של כל טבלה, וצילום השוואה של שלושתן.
- טבלת שש הבדיקות לכל סבב.
- פסקת ההחלטה: איזו שיטה תשמש אתכם מעכשיו, ולמה.

## בדיקה עצמית

| קריטריון | עומד בדרישה | צריך עוד עבודה |
|---|---|---|
| טמפרטורות | בכל סבב הגעתם לטמפרטורת העבודה (מריר 31-32°C) ולא עברתם 32°C אחרי ההזרעה או ההוספה | בסבב אחד או יותר המדחום עבר את 32-34°C, או שלא נמדד |
| בדיקת סכין | בכל סבב התקשה תוך 3-5 דקות, מבריק ובלי פסים, לפני היציקה | יצקתם בלי בדיקה, או שהבדיקה נכשלה ויצקתם בכל זאת |
| ברק | לפחות שתי טבלאות מבריקות כמו מראה בצד התבנית, בלי פסים | פסים, כתמים או עמימות ברוב הטבלאות |
| סנאפ | לפחות שתי טבלאות נשברות בקליק עם קו שבר נקי | הטבלאות מתכופפות או מתפוררות |
| שחרור | לפחות שתי טבלאות יצאו מהתבנית לבד כשהפכתם אותה | צריך לדפוק או לכופף את התבנית כדי להוציא |
| תיעוד | שלוש שורות מלאות ביומן, ושישה צילומים לפחות | שורות חסרות, או טמפרטורות שלא נרשמו |
| החלטה | פסקה מנומקת שמזכירה ציוד, זמן ותנאי החדר | "הכי קל" בלי נימוק |
| בלי בזבוז | כל מה שלא הצליח נמס מחדש או נוצל | שוקולד נזרק |

עמדתם בכל השורות? אתם מוכנים ל[מודול 4](../lessons/module-04/lesson-01.md). נכשלתם בשורה אחת או שתיים? חוזרים על הסבב החלש, עם אותו שוקולד.
